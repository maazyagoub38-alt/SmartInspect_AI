# SmartInspect-AI
### AI-Powered Industrial Defect Detection Using Computer Vision

SmartInspect-AI is a computer vision project designed to support
automated industrial quality inspection.

The project uses a trained machine learning model to analyze
product images and predict whether an inspected product is
normal or potentially defective.

## Project Objectives

- Automate visual product inspection.
- Detect potential product defects using AI.
- Reduce the need for manual inspection.
- Demonstrate a practical computer vision workflow.

## Key Features

- Trained image classification model.
- Image inference and prediction.
- Configurable model settings.
- Confidence score reporting.
- Python-based implementation.

## Technologies Used

- Python
- Computer Vision
- Machine Learning
- Image Processing
- NumPy
- OpenCV
- Pillow
- Streamlit (if used in the application)
